About encoding

Secret alphabets are a fun way to obfuscate notes by substituting each character with another symbol you choose. They are not secure encryption — anyone who knows or discovers the mapping can decode the text. Generated alphabets are still substitution codes, not cryptography.

Secret Mode hides notes and alphabets you mark as secret from the normal lists. Access requires your PIN. The PIN is stored as a PBKDF2 hash using the Web Crypto API — even someone with access to your device cannot recover it from the stored hash. Secret Mode is not a professionally audited secure vault; the underlying note content remains in browser-local storage. For truly sensitive data, use a dedicated password manager.

About

Secret Notes · a single-file notes app with folders, tags, attachments, checklists, secret alphabets, and an optional Secret Mode.

All data is stored locally in your browser (localStorage for text, IndexedDB for attachments). Nothing is uploaded to any server. Use the Export button to back up your data.

Disclaimer

Secret alphabets provide obfuscation, not encryption. Secret Mode adds convenience protection (PIN-gated access), not cryptographic protection of note contents. Do not use this app to store passwords, financial information, or other truly sensitive data.
